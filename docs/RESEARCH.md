# C Cleaner Plus → Deep Cleaner 调研与迁移说明

## 原项目结论

调研对象：`Kiowx/c_cleaner_plus` main 分支（调研时 v0.7.8，Python + PySide6 + Fluent Widgets）。原项目约 1.49 万行单文件主程序，外加 JSON 规则包和 Rust 大文件扫描辅助工具。

原项目的产品主线包括：

- 常规规则清理与空间估算
- 多盘大文件扫描
- 重复文件、空文件夹、无效快捷方式、卸载注册表、右键菜单
- 标准/强力卸载及残留文件、服务、计划任务处理
- Windows 计划任务、开机启动
- 自定义规则导入导出、远程规则商店、国际化、深浅色主题

值得迁移的不是 Windows 路径本身，而是四个设计原则：

1. 扫描和删除分离，用户可逐项勾选。
2. 估算、进度、结果日志可见。
3. 删除操作存在受保护路径拦截。
4. 重复文件、空目录等易误删对象在执行前重新复核。

## Android 功能映射

| C Cleaner Plus | Deep Cleaner | Android 实现 |
| --- | --- | --- |
| 常规清理规则 | 智能清理分类器 | 文件名、扩展名、目录与文件年龄规则 |
| 回收站/永久删除 | 可恢复/永久删除 | `.DeepCleanerTrash` + 内部 JSON 索引；默认关闭 |
| 大文件扫描 | 大文件工具 | 共享存储迭代遍历 + Top-K 最小堆 |
| 重复文件 | 重复文件工具 | 大小预分组 + SHA-256 稳定摘要 |
| 空文件夹 | 空文件夹工具 | 自底向上遍历 + 删除前二次判空 |
| 应用强力卸载 | 应用管理 | 系统 `ACTION_DELETE` 与应用空间管理页 |
| 计划任务 | 自动清理 | WorkManager 唯一周期任务 |
| Windows 系统保护 | Android 路径保护 | 根目录、`Android`、工具回收站、符号链接拦截 |
| 注册表/快捷方式/右键菜单 | 不迁移 | Android 无对应概念 |

## Android 平台边界

Android 11–16 即使授予所有文件访问，也不能访问其他应用位于 `Android/data` 下的应用专属目录。因此“直接清除所有应用缓存”不属于普通第三方清理器可可靠实现的能力。应用管理页会调用系统或目标应用提供的空间管理界面，让用户在操作系统受控流程中处理私有数据。

## 算法与安全

- 遍历：显式栈，避免深目录递归导致栈溢出；协程每个节点检查取消状态。
- 大文件：固定上限的最小堆，避免在内存中持有全盘文件列表。
- 重复文件：只对相同大小且至少两项的组计算摘要，降低 I/O；摘要前后核对长度与修改时间。
- 删除：仅处理上一次扫描形成的候选项；执行前重新核对规范路径、类型、大小或摘要。
- 回收站：跨文件系统移动失败时复制后验证删除；恢复目标冲突时自动重命名，不覆盖现有文件。
